# Changelog

## 0.2.0 (2026-11-23)

The first release of the `synltr` package: one command that genotypes LTR retrotransposon insertions across genome
assemblies and from long reads, tests for gene flow with them, and finds the subgenomes of a polyploid
([README.md](README.md)).

- The scripts this repository held before (`module1.py`, `module2.py`, `module2/ltrharvest_wrapper2.sh` and their
  helpers) moved to `legacy/` with their code unchanged. They still run from there and are no longer maintained;
  [legacy/README.md](legacy/README.md) indexes them. The package does not use them.
- Version 0.1.0 was a development version and was not published.
